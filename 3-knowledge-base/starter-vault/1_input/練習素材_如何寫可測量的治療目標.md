# 如何寫可測量的治療目標

治療目標寫得好不好，最簡單的檢驗是：三個月後，另一位治療師拿著這個目標，能不能判斷「達成了沒有」。
做不到，通常是目標太模糊。

## 常見的模糊寫法

「改善右手功能」「提升日常生活獨立性」。這類句子沒有說誰、做什麼、在什麼條件下、做到什麼程度、什麼時候。

## 一個實用的拆法

把目標拆成五個欄位再組回一句話：

1. **誰**：個案。
2. **做什麼**：具體的活動，例如「用湯匙吃完一餐」。
3. **條件**：在什麼輔助或環境下，例如「使用加粗握柄湯匙、坐在餐桌前」。
4. **程度**：做到什麼標準，例如「不灑出、不需口頭提醒」。
5. **期限**：幾週內。

組起來：「個案在 4 週內，使用加粗握柄湯匙，坐在餐桌前自行吃完一餐，不需口頭提醒。」

## 目標與量表分數的關係

量表分數（例如某個動作功能量表）可以當作追蹤指標，但一個分數的變化是否有臨床意義，要看該量表的研究怎麼定義；
本文不提供任何量表的具體切截值，來源未載，待補。
個案自己最在意的活動，通常比單純的分數目標更能維持動機（這是一般臨床觀點，本文未附文獻，詮釋非實證，不可過度推論）。

## 寫完後的自我檢查

- 目標裡有沒有動詞？沒有動詞的多半是「狀態」，不是目標。
- 有沒有期限？沒有期限就沒有檢查點。
- 是個案想做的事，還是治療師想看到的數字？兩者要分清楚。
