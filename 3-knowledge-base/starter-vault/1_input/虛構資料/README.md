# 虛構資料說明

> [!warning] 這個資料夾裡的內容完全虛構，僅供示範
> 沒有任何真實個案、學生或未發表研究。格式刻意仿照真實的敏感資料，用來練習「敏感資料只交給本機模型」的判斷。

| 檔案 | 用途 |
|---|---|
| `虛構個案_中風後上肢OT評估摘要.md` | 仿真的中風後上肢職能治療初評摘要（個案 A）。含 FMA-UE、ARAT、Box and Block、Barthel、COPM、MoCA 的分數 |
| `虛構學生成績表.csv` | 12 位虛構學生（代號 S01–S12）的成績。總分 = 期中 30% + 期末 40% + 實習評量 30%。檔案有 BOM，Excel 可直接開啟不亂碼 |

## 怎麼用

1. 練習分級：打開 [[資料分級檢查表]]，對這兩個檔案各走一遍。答案：兩個在真實世界都是**敏感**，只能用本機模型。
2. **不要**把這兩個檔案貼給雲端 AI 來「試試看」——練習的重點就是養成不貼的習慣。
3. 需要練習建卡、精煉時，改用 `1_input/練習素材_如何寫可測量的治療目標.md`（公開等級）。
