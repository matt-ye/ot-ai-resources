# 中風後上肢職能治療初評摘要
## 1. 基本資料

| 項目 | 內容 |
|---|---|
| 個案代號 | 個案A |
| 年齡／性別 | 60 多歲／男 |
| 診斷 | 左側大腦中動脈梗塞（缺血性中風），右側上肢偏癱 |
| 發病後時間 | 約 3 個月 |
| 慣用手 | 右手（患側為慣用手） |
| 生活狀況 | 退休，與配偶同住，住家無電梯（二樓） |
| 轉介原因 | 右手功能恢復趨緩，希望提升日常生活自理 |

## 2. 臨床觀察
- 肌肉張力（MAS）：肘屈肌 1+、腕屈肌 2、手指屈肌 1+。
- 右肩半脫位約一指寬，肩部活動末端輕度疼痛（VAS 2/10）。
- 輕度找字困難，但能理解多步驟口語指令；情緒穩定，治療動機高。
- 步行：使用單點拐杖，室內與社區短距離可行走。

## 4. 治療目標與計畫
| 期程 | 目標 |
|---|---|
| 短期（4 週） | 右手能抓握加粗握柄湯匙，完成 10 口進食動作；ARAT 抓握分項 +2 |
| 中期（8 週） | 口語提示下，右手協助完成上衣 3 顆釦子；COPM 目標 1、2 表現與滿意度各提升 2 分以上 |
| 長期（12 週） | 右手可擰乾毛巾並協助洗澡；Barthel 提升至 85 以上；FMA-UE 提升至少 6 分 |

介入（任務導向訓練為主）：

- **任務導向訓練**：把進食、扣釦、擰毛巾拆成可練習的子任務，每次 45 分鐘、每週 3 次；難度依成功率 70–80% 調整。
- **重複性功能練習**：抓放不同大小物件、前伸取物，以 Box and Block 類活動監測進度。
- **張力與肩部管理**：擺位與副木評估、肩部保護教育（避免拉扯患側手臂）。
- **環境與輔具**：加粗握柄餐具、防滑墊、扣釦輔具試用。
- **居家計畫**：配偶參與教學，每日 20 分鐘居家練習，附練習紀錄表。
- **再評估**：每 4 週複測 FMA-UE、ARAT、Box and Block；每 8 週複測 Barthel 與 COPM。
