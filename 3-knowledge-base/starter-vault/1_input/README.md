# 1_input：你丟新素材的地方

## 這裡放什麼

任何還沒整理的素材：論文 PDF、課程講義、會議記錄、影片逐字稿、行政文件、你自己的筆記。
**丟進來就好，不必先分類，原檔不要改名、不要搬走。**

## 規則

1. **丟之前先判斷資料等級**（見 [[資料分級檢查表]]）。敏感資料（病歷、學生成績與作業、學生錄音、未發表研究）
   不能請雲端 AI 處理，也不要為了「讓 AI 看得到」而放進這個資料夾然後叫雲端 AI 去讀。
2. `_extracted/` 放「轉成純文字的版本」。AI 讀這一層，不直接讀 pdf、pptx、docx 原檔——文字版又快又省額度，
   也比較不會讀錯表格。怎麼轉見 [[新資料進料]]。
3. 處理完的批次，經你同意後再移到你自己建立的封存資料夾（流程見 [[清理與封存]]）；AI 不會自動搬、不會自動刪。
