# 決策紀錄

只記會影響以後工作的決定。新紀錄加在最上方，不改寫舊紀錄；決定被取代時，在舊紀錄標 `superseded_by`。
寫法見 [[交接與決策紀錄]]。

## 範本（複製後改寫，不要直接改這一段）

### YYYY-MM-DD｜一句話標題

- **決策**：（決定了什麼）
- **理由**：（為什麼；碰到什麼問題或什麼證據）
- **怎麼套用**：（以後遇到什麼情況就怎麼做，寫成可執行的步驟）

## 紀錄

### 2026-11-25｜這個知識庫的資料分級採三級，不確定當敏感

- **決策**：沿用 [[CLAUDE]] 的綠／黃／紅三級；不確定時一律當紅，先問使用者，不自行降級。
- **理由**：把敏感資料誤送雲端是無法收回的錯；多問一次的成本很低。
- **怎麼套用**：每次丟新檔進 `1_input/`，先用 [[資料分級檢查表]] 判級，再決定能用哪種 AI。
- **推翻條件**：機構公布新的資料治理規範，或你取得可用於該類資料的正式授權。
