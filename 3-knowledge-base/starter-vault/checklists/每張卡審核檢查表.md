# 每張卡審核檢查表

> 用法：審核每一張 AI 草稿時，從上到下勾。全部勾完才能升級（把 `maturity` 改掉、移除 `ai-draft` tag）。流程見 [[審核草稿]]。
> 一張卡約 3–5 分鐘；超過就代表卡片太雜，考慮拆卡。

## A. 主張

- [ ] 「主張」一到兩句，能單獨說完？
- [ ] 只有一個主張？（有兩個就拆卡）
- [ ] 不是內容摘要（不是「這份資料講了 A、B、C」）？

## B. 證據與來源

- [ ] 每個數字都寫了分母與來源？
- [ ] 隨機挑一個數字，回原始來源找得到？（至少抽查一個）
- [ ] 查不到的地方寫了 `來源未載，待補`，並且 `needs_evidence: true`？
- [ ] 沒有 AI 編出來的作者、年份、DOI、頁碼？（可疑就回文獻管理軟體或原始頁面核對）
- [ ] 沒有整段貼上他人原文？

## C. 詮釋與推論

- [ ] 你自己的看法，有標「詮釋非實證，不可過度推論」？
- [ ] 沒有把「很多人這樣做」寫成「這樣做才對」？
- [ ] 沒有超出證據的保證語氣（一定、保證有效、證明）？

## D. 格式

- [ ] 必填欄位齊全：`type`、`themes`、`ip`、`maturity`？
- [ ] `ip` 值是 自有／他人需標註／通用或公共領域 之一？
- [ ] 他人內容的卡有寫出處，`ip` 選對？
- [ ] 有連到至少一張 MOC，MOC 也有連回這張卡？
- [ ] 存檔後檢查沒有報錯？

## E. 處置（三擇一）

- [ ] 升級：改 `maturity`、移除 `ai-draft` tag
- [ ] 退回補：在卡末加「審核備註（日期）」，寫缺什麼
- [ ] 淘汰：請使用者決定，不要直接刪，依 [[清理與封存]] 辦理

## 資料等級再確認

- [ ] 卡片內容裡沒有個案、學生或未發表研究的可識別資訊？（見 [[資料分級檢查表]]）
