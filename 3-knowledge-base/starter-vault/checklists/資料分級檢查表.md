# 資料分級檢查表

> 用法：每次要請 AI 處理一份資料之前，從上往下問。**只要有一題答「是」，就是紅色（敏感）**。
> 全部答「否」才往下看黃或綠。**不確定就當紅，先問負責人（指導教授、單位主管或你的 IRB 窗口）。**

## 第一關：這份資料是紅色嗎？

- [ ] 裡面有病人或個案的資料（病歷、評估紀錄、治療紀錄、照片、影片），即使看起來已去掉姓名？
- [ ] 裡面有學生的資料（成績、作業、報告、考卷、評語、出缺席）？
- [ ] 錄音或逐字稿裡有學生、個案、家屬或同事的發言？
- [ ] 是還沒發表的研究：資料、分析結果、投稿中或審查中的稿件？
- [ ] 跟 IRB 有關：受試者資料、同意書、IRB 申請內容？
- [ ] 有人沒同意被拿去給第三方服務處理？

任何一題答「是」→ **紅**：只能用本機模型，或自己處理。不要貼進雲端 AI，不要上傳雲端轉錄或翻譯服務。

## 第二關：是黃色（內部）嗎？

- [ ] 是自己編的教材、投影片、題庫（尚未公開）？
- [ ] 是已去識別、且無法回推到個人的統計結果？
- [ ] 是行政文件（公文、會議議程、課程規劃），沒有個人敏感資訊？

任一題答「是」→ **黃**：只用機構提供的方案，或商業方案且服務條款載明「不將你的輸入用於訓練」。不確定條款內容，就查條款或問資訊單位。

## 第三關：是綠色（公開）嗎？

- [ ] 已發表文獻、公開指引、公開網頁、公開演講？
- [ ] 這份資料外流也不會造成任何人的損失？

都「是」→ **綠**：可用任何雲端模型。但引用他人內容要標出處，AI 給的出處要回原始來源核對。

## 降低等級的做法（不是降級）

很多任務不需要真實識別資訊也能做。**去識別不等於降級成綠**，做法：

- 人名、機構名換成代號（個案 A、S01）。
- 刪掉出生日期、地址、病歷號、罕見診斷加地區這類能回推到個人的組合。
- 不要整份 PDF 直接上傳，只貼需要的片段。
- 去識別後如果仍有「這是誰」的可能，仍當紅。

## 練習

打開 `1_input/虛構資料/` 的兩個檔案各走一遍（完全虛構，但依敏感資料處理）。參考答案：兩份都是紅。
