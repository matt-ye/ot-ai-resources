# SOP：新資料進料

> **何時讀這份**：使用者丟了新檔進 `1_input/`，或要處理還沒精煉的素材時。其他時候不必載入。

## 步驟

### 1. 先判斷資料等級（任何處理之前）

用 [[資料分級檢查表]] 判斷綠／黃／紅。**紅色（敏感）資料不要自己讀進對話，也不送雲端**：
停下來告訴使用者「這份屬敏感，需要本機模型或你自己處理」，等指示。不確定就當紅。

### 2. 盤點，不動原檔

列出 `1_input/` 裡新增的檔案（檔名、類型、大小、大約內容）。**原檔不改名、不搬移、不刪除。**
先看資料夾裡有沒有 README 或清單可查，不要遞迴掃全庫。

### 3. 轉成純文字，放進 `1_input/_extracted/`

- 已經是 `.md`、`.txt`：直接讀，不必轉。
- PDF、Word、PowerPoint：請使用者先另存成文字或 Markdown，或用你的工具轉；轉好的版本放 `1_input/_extracted/`，檔名用「原檔名.md」，並在檔案開頭 frontmatter 寫 `source`（原檔名）與 `quality`（`ok`＝文字正常；`needs_check`＝表格或圖可能走樣；`scanned`＝掃描圖檔，需要 OCR 或人工）。
- 掃描件或圖片 PDF：標 `scanned`，告訴使用者，不要硬讀、不要猜內容。

### 4. 精煉成摘要，放進 `2_compression/<批次名>/`

只讀 `_extracted/` 的文字版。摘要要包含的項目見 `2_compression/README.md`。
學術文獻另外照 [[文獻萃取入庫]]；錄音照 [[會議與課程錄音]]。
**原文說的、你整理的、你推測的，要分開寫。查不到的寫 `來源未載，待補`。**

### 5. 提案，不直接建卡

列出建議的卡片清單：每張一行，寫「卡名＋一句主張＋對應領域 MOC」。**等使用者核准後**才進 [[建卡]]。

### 6. 登記

在 `4_gap/待辦_未處理資產.md` 登記這份素材的處理狀態；更新 [[CURRENT_HANDOFF]]。

## 完成檢查

- [ ] 資料等級已判斷並寫在摘要裡
- [ ] `_extracted/` 與 `2_compression/` 的檔案都在磁碟上（回去數過，不靠回報）
- [ ] 建卡提案已交給使用者，沒有偷偷建卡
- [ ] 待辦已登記

> 然後精煉到 2_compression，最後給我一份建卡提案，我核准之前不要寫進 cards。
