# 3-knowledge-base：讓 AI 和半年後的你，都不用從頭問起

## 這是什麼

一個**可以直接下載使用的 Obsidian 知識庫範本**（`starter-vault/`）。
Obsidian 是一套在自己電腦上管理 Markdown 筆記的免費軟體；你的筆記只是一個個文字檔，不綁在任何公司的伺服器上。

這個範本解決的問題：你用 AI 讀了論文、聽了課、開了會，過兩週就忘了結論放在哪、哪些是 AI 編的、哪些資料不該給 AI 看。
範本把這些做成固定結構與規則：

- **資料夾結構**：素材 → 精煉摘要 → 一卡一主張的知識卡，每一層放什麼都有規定。
- **規則檔 `CLAUDE.md`**：用 Claude Code 這類 AI 程式工具（可以讀寫你電腦裡檔案的 AI）開啟這個資料夾時，規則會自動生效：
  敏感資料不送雲端、AI 寫的卡一律標「AI草稿」、查不到的來源要寫「來源未載，待補」。
- **存檔後自動檢查（hook）**：AI 每次寫入 `.md` 檔，一支小程式會立刻檢查格式（必填欄位、斷掉的連結等），有問題就退回給 AI 重做。
- **八份 SOP**：給 AI 讀、你也能照做的作業流程，涵蓋論文、課程、會議、影片逐字稿、行政文件。
- **交接檔**：換工具、換對話視窗、隔半年回來，都從 `5_dialogue/` 接得上。

**不需要會寫程式。** 沒有 Claude Code 也能用 Obsidian 手動整理，只是沒有自動檢查與 AI 協助。

## 你需要先準備

| 項目 | 必要？ | 說明 |
|---|---|---|
| Obsidian | 必要 | 到 Obsidian 官方網站下載安裝（Windows、Mac 都有，個人使用免費）。`.base` 檔（表格視圖）需要較新版本，建議更新到最新版；以官方說明為準 |
| 下載本範本 | 必要 | 從 GitHub 頁面下載整個 repo 的 ZIP 並解壓縮，之後只用 `3-knowledge-base/starter-vault/` 這個資料夾。**複製到一個固定、不會被同步工具搶改的位置**（例如文件資料夾底下），不要放在雲端同步資料夾的「共用」區 |
| Python 3 | 選用；**要跑下面的自我檢查就必要** | Mac 通常內建或會在第一次使用時提示安裝；Windows 可從 python.org 安裝。只用標準函式庫，不需要另外裝套件 |
| Claude Code | 選用 | 在終端機運作的 AI 程式工具，需要登入帳號與可用的方案或額度（費用與條件以官方為準）。安裝請看官方文件 https://code.claude.com/docs ，版本更新很快，這裡不抄指令。沒有它也能做：只照第一天 SOP 的 0–3 分鐘、丟檔與審核，其餘改成自己手動寫卡 |

## 安裝（約 10 分鐘）

### 1. 用 Obsidian 打開範本

1. 打開 Obsidian，在歡迎畫面選「Open folder as vault」（開啟資料夾作為資料庫）。
2. 選你解壓縮後的 `starter-vault` 資料夾。
3. **預期看到**：左邊檔案列有 `1_input`、`cards`、`sop` 等資料夾；點 `MOC 總圖` 能打開並看到藍色連結。
4. 若跳出「信任這個資料庫的外掛」之類的提問，本範本沒有第三方外掛，可選不啟用。
5. **沒看到？** 確認選的是 `starter-vault` 本身，而不是它的上一層。

### 2.（選用）裝 Claude Code，並讓檢查程式對得上你的系統

**在哪裡做**：終端機。Windows 開「終端機」或 PowerShell；Mac 開「終端機」App。
先用 `cd` 切到 `starter-vault`（例如輸入 `cd ` 加一個空格，把資料夾從檔案總管或 Finder 拖進視窗，按 Enter）。

存檔後檢查有兩支程式，**行為相同**，看你的系統用哪一支：

> **關於 `-ExecutionPolicy Bypass`**：Windows 預設會擋沒有簽章的腳本，所以設定裡加了這個選項。它只對這一次執行有效，只會執行 `scripts/validate_md_write.ps1` 這支檔案，不會改變你電腦的設定。想先看內容，用記事本打開那支檔案即可；不放心就不要裝這個檢查。

| 你的系統 | 用哪一支 | `.claude/settings.json` 要不要改 |
|---|---|---|
| Windows | `scripts/validate_md_write.ps1`（用 Windows 內建的 PowerShell） | 不用改，範本預設就是這支 |
| Mac | `scripts/validate_md_write.py`（需要 Python 3） | 要換成 Mac 版設定，見下 |

**Mac 換設定**（在 `starter-vault` 資料夾的終端機裡貼這一行，作用是把 Mac 版設定複製成正式設定，讓 Claude Code 改呼叫 `.py`）：

```
cp .claude/settings.mac.json .claude/settings.json
```

Mac 先確認有 Python 3：輸入 `python3 --version`，看到版本號就可以；沒有的話系統會提示安裝。

Windows 若想改用 `.py` 版（例如你不想用 PowerShell），把 `.claude/settings.json` 裡 `command` 那行改成 `py -3 "$CLAUDE_PROJECT_DIR/scripts/validate_md_write.py"`（需要已安裝 Python）。一般不需要。

### 3. 先確認檢查程式有效（重要）

**在哪裡做**：`starter-vault` 資料夾的終端機。**為什麼要跑**：這個檢查程式壞掉時會「悄悄放行」而不是報錯，所以要主動確認它會擋人。這支測試只確認**檢查程式本身**會擋；Claude Code 有沒有真的叫到它，要靠第一天 SOP 的 22–26 分鐘實測。

```
Windows：  python scripts/hook_selftest.py   （找不到 python 就改打 py）
Mac：      python3 scripts/hook_selftest.py
```

**預期看到**：每支檢查一行 `PASS`（Windows 兩行，Mac 一行）。這支測試會暫時建立一張缺欄位的卡，確認被擋下、中文路徑顯示正常，再建一張合格的卡確認放行，然後把暫時檔刪掉。
**看到 `FAIL`？** 照訊息處理；常見原因見下方「常見問題」。

## 第一天 30 分鐘 SOP

目標：走完一輪「丟檔 → 精煉 → 提案 → 核准 → 建卡 → 格式退回 → 審核」，你就會用了。

| 分鐘 | 步驟 | 在哪裡做 | 預期看到 | 沒看到怎麼辦 |
|---|---|---|---|---|
| 0–3 | **打開並認識** | Obsidian | 打開 `MOC 總圖`（MOC＝地圖頁，把相關的卡連在一起）、`學術寫作 MOC`，點進一張卡 | 連結不是藍色：到 Obsidian 設定確認有開啟 wikilink（內部連結）功能 |
| 3–5 | **打開 AI** | 終端機，在 `starter-vault` 資料夾輸入 `claude`（可能需要先信任此資料夾，選信任） | AI 進入對話 | 找不到 `claude` 指令：Claude Code 沒裝好，回安裝步驟 |
| 5–7 | **確認規則生效** | Claude Code 對話框，貼：`請讀 CLAUDE.md 和 5_dialogue/CURRENT_HANDOFF.md，用五句話告訴我你要遵守的規則。` | AI 會講到：敏感資料不送雲端、先提案後建卡、AI 草稿標記、來源未載待補 | AI 沒提到：請它再讀一次並逐條複誦；仍不行就貼 `CLAUDE.md` 的紅線段落給它 |
| 7–10 | **丟一個檔** | 檔案總管或 Finder | 範本已附 `1_input/練習素材_如何寫可測量的治療目標.md`（公開等級），這次用它。下次丟自己的檔：**先照 `checklists/資料分級檢查表.md` 判級** | 自己的檔是病歷、成績、學生錄音、未發表研究：**不要丟給雲端 AI**，見常見問題 |
| 10–15 | **請 AI 精煉** | Claude Code，貼下方範例 1 | `2_compression/` 出現一個新資料夾與摘要；摘要標了資料等級；AI 給你一份建卡提案（只是清單，還沒建卡） | AI 直接建卡：提醒它「先提案後建卡」，請它撤回（用你在 Obsidian 看到的新檔，確認後請 AI 說明哪些要刪，**由你決定**） |
| 15–18 | **你核准** | Claude Code | 你看提案：每張卡是不是只有一個主張？不合理的請它改，合理的回「核准，建這幾張」 | 提案像摘要而不是主張：請它重寫成「一句話主張」清單 |
| 18–22 | **建卡** | Claude Code，貼範例 2 | `cards/` 底下出現 AI草稿卡；AI 每建一張會說格式檢查通過 | 檢查報錯：AI 會自己改；改不好請它把報錯訊息整段貼給你看 |
| 22–26 | **體驗格式退回** | 檔案總管或 Finder 把 `examples/退回示範_缺欄位的卡.md` 複製到 `cards/學術寫作/`；然後在 Claude Code 說：`請在 cards/學術寫作/退回示範_缺欄位的卡.md 最後加一行「測試」。` | 存檔後檢查擋下，AI 回報缺 `ip`、`maturity`；你請它補齊（`ip: 自有`、`maturity: "AI草稿"`） | 沒被擋：回安裝步驟 3 重跑自我檢查。練習完把這個複製品**自己**移到資源回收桶，AI 不會幫你刪 |
| 26–30 | **審核** | Obsidian，打開 `AI草稿審核.base` | 「待審 ai-draft」表格列出所有 AI 草稿，包含範本附的 7 張示範卡 | 表格是空的：確認 Obsidian 版本夠新，且卡片 frontmatter 有 `tags` 含 `ai-draft` |

**範例 1（精煉）**

> 請讀 sop/新資料進料.md。1_input 裡的「練習素材_如何寫可測量的治療目標」是公開資料。
> 請精煉成摘要放進 2_compression，再給我一份建卡提案（卡名＋一句主張）。我核准之前不要寫進 cards。

**範例 2（建卡）**

> 提案我核准了。請讀 sop/建卡.md，照提案建卡，全部標 AI草稿。每張建完確認格式檢查沒報錯，最後在 MOC 加連結並更新 5_dialogue/CURRENT_HANDOFF.md。

**審核時怎麼做**：每張卡照 `checklists/每張卡審核檢查表.md` 勾三關——主張只有一個、數字回得到來源、詮釋沒被寫成結論。
**這個動作 AI 不能代替你做**：把 `maturity: "AI草稿"` 改掉、移除 `ai-draft` tag，是你的核准動作。

> 範本附的 7 張示範卡都是 AI 草稿，**其中的百分比是「講者專案聚合統計」**，已標分母，只描述寫法分布，不是方法學標準答案。
> 三張標了 `needs_evidence: true`（來源待補）。引用前請回原始文獻核對。

## 每週 15 分鐘 SOP

固定一個時間（建議每週同一天），不要等累積了才處理。

| 分鐘 | 做什麼 | 在哪裡 | 要人看 |
|---|---|---|---|
| 0–8 | **審草稿**：開 `AI草稿審核.base` 的「待審 ai-draft」，最舊的先審，一次 5–10 張。每張照審核檢查表：升級／退回補／淘汰。流程見 `sop/審核草稿.md` | Obsidian | **一定要你看** |
| 8–11 | **清待辦**：開 `4_gap/待辦_未處理資產.md`，把這週丟進 `1_input/` 但還沒處理的登記或處理。看 base 的「待補文獻」視圖，挑一兩張補來源 | Obsidian | 你決定要不要處理 |
| 11–14 | **更新地圖**：這週新升級的卡，確認有連到對應 MOC；有新領域就複製 `學術寫作 MOC` 的格式新增一張，並在 `MOC 總圖` 加一行 | Obsidian | 你決定怎麼分類 |
| 14–15 | **交接**：請 AI 更新 `5_dialogue/CURRENT_HANDOFF.md`，有新決定追加到 `DECISIONS.md`（`sop/交接與決策紀錄.md`） | Claude Code | 你看一眼 |

每月一次：跑 `hook_selftest.py` 確認檢查還有效；需要整理檔案時照 `sop/清理與封存.md`（AI 只提案，你核准才動）。

## 哪裡用 AI、哪裡一定要人看

| 環節 | AI 做 | 你一定要做 |
|---|---|---|
| 判斷資料等級 | 可以幫你問檢查表的問題 | **最終判斷是你的**；不確定當敏感 |
| 轉文字、精煉 | AI 做 | 看摘要裡「原文說的」與「AI 推測的」有沒有分開 |
| 建卡提案 | AI 做清單 | **你核准才建卡** |
| 建卡 | AI 做 | 抽查數字與出處 |
| 升級草稿 | 只能做第一輪檢查 | **你改 maturity** |
| 刪除、搬移、改名 | 只能提案 | **你核准才執行** |
| 格式檢查 | 程式自動做 | 偶爾跑自我檢查 |

## 檔案結構

```
starter-vault/
  CLAUDE.md                 給 AI 的規則（100 行內），觸發式指向 sop/
  AI_COLLABORATION.md       多個 AI 或多個工作階段的交接規則
  MOC 總圖.md               入口地圖；另有 2 個示範領域地圖
  AI草稿審核.base           待審草稿與待補證據的表格視圖
  1_input/                  丟素材處（_extracted/ 放純文字版；虛構資料/ 練習分級）
  2_compression/            精煉摘要
  cards/                    知識卡（各類資料夾；7 張示範卡）
  3_discovery/  4_gap/      跨領域發現；缺口與待辦
  5_dialogue/               CURRENT_HANDOFF、DECISIONS（空白範本）
  sop/                      八份 SOP
  checklists/               資料分級檢查表、每張卡審核檢查表
  examples/                 故意缺欄位的退回示範卡
  scripts/                  存檔後檢查（.ps1 與 .py）、自我檢查、schema
  .claude/                  settings.json（Windows）、settings.mac.json（Mac）
```

## 常見問題

**自我檢查顯示 FAIL，怎麼辦？**
先看訊息。Windows 若 `.ps1` 那行失敗，確認不是被公司或學校電腦的 PowerShell 執行原則擋住（`settings.json` 已加 `-ExecutionPolicy Bypass`，但自我檢查若被資安軟體攔截，請詢問資訊單位）。
Mac 失敗，確認 `python3 --version` 有版本號，且已執行 `cp .claude/settings.mac.json .claude/settings.json`。

**我手動在 Obsidian 改卡片，格式檢查會跑嗎？**
不會。檢查只在 AI 透過 Claude Code 寫入檔案時觸發。你手動改的卡，可以請 AI「檢查 cards/ 底下所有卡的格式」，或把檔案請它重新存一次。

**我的素材是 PDF，AI 讀得到嗎？**
請先轉成文字放進 `1_input/_extracted/`（`sop/新資料進料.md` 有說明）。掃描圖檔的 PDF 需要 OCR，AI 不應該硬讀猜內容。

**我的資料是病歷、學生成績或學生錄音，能不能用 AI？**
只能用本機模型（跑在你自己電腦上、不連網的模型），或你自己人工處理。本範本**不附本機模型的安裝設定**，請洽資訊單位或有經驗的同事。
在那之前，這些資料不要放進 `1_input/` 讓雲端 AI 讀。

**可以用 Claude Code 以外的 AI 工具嗎？**
可以手動使用：把 `CLAUDE.md` 的內容貼到該工具的規則檔或對話開頭。但**存檔後自動檢查是 Claude Code 的功能**，其他工具不一定有；沒有的話你要自己定期請 AI 跑格式檢查。

**AI 不照規則做怎麼辦？**
規則檔是「要求」不是「強制」。AI 可能忘記或曲解。所以才需要三道人工關卡（核准提案、審核草稿、核准刪除）與自動格式檢查。發現違規，就把規則原文貼回去要求重做，並考慮寫進 `5_dialogue/DECISIONS.md`。

**卡片檔名可以改成英文嗎？**
可以，但要同步修正所有連到它的 wikilink；改名屬於「批次改名」要先經你核准。

## 誠實的限制

- **AI 草稿會堆積。** 建卡很快、審核很慢。如果每週不排時間審，草稿會越積越多，最後沒人敢信。寧可少建卡，也不要讓草稿超過你一週能審的量（經驗上一週審 5–10 張是可行的，個人差異大）。
- **格式檢查不等於內容正確。** 檢查程式只看欄位與連結，不知道數字是不是真的。內容靠你與「獨立查核」。
- **AI 會編造。** 書目、作者名單、DOI、數字都可能是編的。範本的規則是「查不到寫來源未載，待補」，但只能降低風險，不能消除。
- **規則檔不是保證。** AI 可能不遵守；敏感資料最穩的防線是「根本不放進它能讀到的資料夾」。
- **只在 Windows 實測過。** 範本的兩支檢查在 Windows 上實跑通過；Mac 版 `.py` 只用標準函式庫、跨平台寫法，但**尚未在 Mac 上實跑**。如果你在 Mac 遇到問題，請回報。
- **示範卡的數字來自特定語料**（見卡內說明），只描述寫法分布，不代表方法學標準。
- **不含本機模型設定、不含轉錄與 PDF 轉文字工具。** 這些依各人電腦與機構規範而異。
- **Claude Code 需要帳號與費用**，版本更新快，操作畫面可能和這裡描述的不同。
