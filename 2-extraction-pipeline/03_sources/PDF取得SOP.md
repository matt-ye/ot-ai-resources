# PDF 取得 SOP（白話版）

> 授權：CC BY-NC 4.0。

## 原則

1. 由「容易、合法、可程式化」往「麻煩、要人處理」排。前一層拿得到，就不要往下一層。
2. 只用各網站明文允許程式使用的管道。**不要用程式去爬一般網頁，也不要試圖繞過網站設下的驗證或登入限制**；那些網站沒有允許，也可能讓你的網路被封鎖。
3. 每個檔案拿到後，都要做「驗證四級」（見 `驗證四級與攔截規則.md`）。
4. PDF、全文不放進公開 repo，只放你本機。

## 七層順序

| 層 | 做法 | 誰做 | 說明 |
|---|---|---|---|
| 1 | 手邊已有 | 人★ | 先清點自己電腦、文獻管理軟體（如 Zotero、EndNote）、實驗室共用雲端有沒有。最便宜，也最少被忽略。 |
| 2 | 用 DOI 查 PMCID | 程式 | PMCID 是 PubMed Central（PMC，免費全文資料庫）給論文的編號。NCBI 提供「ID 轉換」服務：輸入 DOI 或 PMID，回傳有沒有 PMCID。沒有 PMCID 就代表 PMC 沒收，直接往下一層。 |
| 3 | PMC 開放資料桶 | 程式 | 有 PMCID 且授權允許下載者，用 PMC 官方公布的雲端資料桶（AWS 上的開放資料）取得 XML 或 PDF。它是 PMC 官方列明、允許程式大量下載的管道。**PMC 官方只允許其列明的程式化服務**（如這個資料桶、E-utilities、OAI-PMH 等）；一般的網頁（你用瀏覽器看的那些頁面）不是給程式爬的，不要爬。哪些服務目前可用，以 PMC 官網的說明為準；本文不保證現況。 |
| 4 | 預印本 API | 程式 | 如果論文有預印本（還沒審稿的版本，如 bioRxiv、medRxiv），可用它們官方的 API 取得。注意：預印本與正式版數字可能不同，驗證時要標記。 |
| 5 | Unpaywall／OpenAlex | 程式 | 這兩個服務會告訴你「某 DOI 有沒有合法的免費版本、在哪裡」。Unpaywall 要求請求時附上你自己的聯絡信箱。它們只給連結，檔案仍要從那個連結的來源下載，並遵守該處條款。 |
| 6 | 出版社官方 API | 程式（需先申請） | 部分出版社提供給研究者的全文 API，要先申請金鑰（金鑰＝通行密碼，不要貼到公開地方）、同意條款，通常限用於非商業研究與文字探勘。申請由人做，條件以出版社為準。 |
| 7 | 機構訂閱與館際合作 | 人★ | 透過學校圖書館的訂閱、館際合作（跨館借閱論文）或直接寫信向作者索取。這一層只能由人處理，不要請程式或 AI 代做。 |

## 每一批下載後的清點（程式＋人★）

1. 數量：預期幾篇、實際拿到幾篇、缺哪幾篇（寫進 `papers.csv` 的「取得狀態」）。
2. 檔名：統一用 `PMID_<編號>.pdf`，避免兩篇同名互相覆蓋。
3. 開檔：用 PDF 閱讀器打開，看頁數是否合理（只有 1 頁的多半是預覽頁）、第一頁題名是否是你要的那篇。
4. 真假：檔案若打不開、或其實是網頁存成 `.pdf`，丟棄重取。
5. 然後才進「驗證四級」。

## 取不到時

- 記錄在 `papers.csv`「取得狀態」：`待取`、`已取得`、`取不到（原因）`。
- 取不到的篇數與原因要寫進最終報告：它們是「沒納入」，不是「沒有」。
- 不要用 LLM 憑記憶補寫那篇的數字；沒有全文就是沒有。

## 本 SOP 的限制

- 各服務的條款與介面會變動，執行前請看一次官方說明；本文是流程骨架，不是法律意見。
- 免費全文也可能有使用限制（例如只能個人研究使用、不能再散布）。把全文貼給外部 LLM 前，先確認條款，不確定就問館員。
