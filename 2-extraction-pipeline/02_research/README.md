# ② 研究：請多個 AI 代理平行查資料，但要管得住

> 授權：程式 MIT、文件 CC BY-NC 4.0。

## 這是什麼

「代理」（agent）＝一個被你交代任務、可以自己查資料、讀檔、寫檔的 AI 對話。規劃好之後，常需要請好幾個代理同時查不同範圍的資料（例如「這個量表有哪些常用版本」「這個領域的檢索詞」）。代理很會寫出看起來很像真的內容，所以要有**交辦單**（把任務寫清楚）、**抽驗**（主代理抽查）、**獨立查核**（沒參與的代理再查一次）、**人決定採納**。

## 你需要先準備什麼

- 做完 `01_plan/` 的專案說明書。
- 一個能開多個對話或代理的 AI 工具（任何一種都可以；沒有的話，可以在不同對話視窗各貼一張交辦單）。
- 一個放「代理回報」的資料夾（每個代理一個檔案）。

## 檔案

| 檔案 | 用途 |
|---|---|
| `交辦單_範本.md` | 六要素交辦單，每個代理一張 |
| `主代理抽驗清單.md` | 收回報後，主代理（或你）逐條勾 |
| `獨立查核代理_prompt.md` | 貼給「沒參與的代理」的提示 |

## 逐步 SOP

1. **（LLM）主代理拆題目。** 在哪裡做：你的主對話。貼上：「依專案說明書，把題目拆成互相不重疊的小範圍，每個範圍一張交辦單，用 `交辦單_範本.md` 的格式。」預期：得到 3–6 張交辦單。沒看到：範圍有重疊就請它重拆，「互斥」是第一要件。
2. **（人★）看交辦單。** 逐張確認「唯一資料來源」與「硬規則」。這是你唯一便宜的把關時機。
3. **（LLM）子代理平行查。** 每張交辦單貼到一個獨立對話。**交辦單要寫「禁止再派子代理」**，否則代理可能再轉派，出錯時找不到責任。
4. **（LLM＋人★）主代理抽驗。** 用 `主代理抽驗清單.md`。**子代理的「我做完了」不算數**，要打開它寫的檔案看。
5. **（LLM）獨立查核。** 開一個全新對話，貼 `獨立查核代理_prompt.md`＋回報檔。
6. **（人★）決定採納哪些。** 有被查核代理標「疑似編造」或「來源不符」的，回原始網頁或論文看過再決定。

## 哪裡用 LLM、哪裡一定要人

- LLM：拆題、查資料、抽驗、查核。
- 人★：看交辦單、最後採納。

## 限制

- 代理可能「沒上網卻說查不到」，也可能憑記憶寫出不存在的出處；任何出處、作者名單、年份、卷期、DOI 都要回官方資料庫（如 PubMed）核對。
- 查核代理也是 LLM，不是真相來源；它只是第二雙眼睛。
