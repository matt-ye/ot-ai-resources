# 主代理（或你）的抽驗清單

> 子代理說「完成」不算數。對每一個子代理，逐條勾。建議每個範圍至少抽 3 個檔案或 10%，取多者。

## A. 磁碟上有沒有東西（程式或人，約 2 分鐘）

- [ ] 回報的檔案清單，實際都在輸出資料夾（用檔案總管或指令數一下）。
- [ ] 輸出資料夾以外沒有被改動的檔案。
- [ ] 檔名符合命名規則（沒有空格、雙副檔名、無編號）。
- [ ] 沒有空檔案或只有標題的檔案。

## B. 格式（程式可做）

- [ ] 每個檔案的欄位都齊全（模板的每一欄都在）。
- [ ] 「status」都是 draft，沒有人偷改成 final。

## C. 內容（要人看）

- [ ] 隨機抽 3 個「證據位置」，打開原始資料核對：位置存在嗎？內容與主張相符嗎？
- [ ] 隨機抽 3 個出處（PMID／DOI），到 PubMed 或 Crossref 查：題名、作者、年份對得上嗎？
- [ ] 有沒有原文段落被直接貼進來？有就退回。
- [ ] 「未確認」欄是否誠實？（全部都寫「無」是警訊。）
- [ ] 有沒有兩個代理寫了同一件事（範圍重疊）？

## D. 判定

| 結果 | 做什麼 |
|---|---|
| 抽驗全過 | 進獨立查核 |
| 有 1–2 處錯 | 退回該代理並列出錯誤，重做後再抽驗 |
| 錯誤多或發現編造 | 整個範圍作廢，改派新代理，並在 `06_iterate/` 記錄原因 |
