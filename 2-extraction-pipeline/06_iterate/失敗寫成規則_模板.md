# 失敗寫成規則：模板

> 授權：CC BY-NC 4.0。每次失敗填一張。五欄都要填；原因不確定就寫「未確認」。

| 欄位 | 怎麼寫 | 常見錯誤 |
|---|---|---|
| 日期 | 發生日，YYYY-MM-DD | 寫「最近」 |
| 現象 | 你**看到**什麼（數字、錯誤訊息），不含猜測 | 把原因當現象寫 |
| 原因 | 有證據的原因；沒證據寫「未確認」，並寫你打算怎麼查 | 憑感覺下結論 |
| 規則 | 一句祈使句，下次開工前要遵守 | 寫成「要小心」「注意品質」 |
| 怎麼檢查 | 誰、在哪個時間點、用什麼方法確認規則被遵守；最好能由程式檢查 | 寫「人工留意」 |

## 範例（填好）

- 日期：2026-09-05
- 現象：一個比率（某軟體使用率）算出 56%，後來用另一條管線測得約兩成。
- 原因：LLM 在欄位寫「未載明」這類否定句，關鍵字比對看到軟體名稱就算命中。證據：改成排除否定句的比對後，比率降到 16%。
- 規則：重要比率不能只靠一條管線的關鍵字統計；要有第二條獨立管線互證，並排除否定語境。
- 怎麼檢查：交出任何比率前，說明書的驗收標準要求「兩條管線的結果並列」；方向不同就擋下，由人看原文。

## 寫回規劃

規則確認後，把它加進 `01_plan/` 說明書的哪一欄（紅線／停止條件／驗收標準），並寫在「日期化補充」。
