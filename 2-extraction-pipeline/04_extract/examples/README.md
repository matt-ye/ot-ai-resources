# examples：5 篇的萃取數字

> 授權：文件 CC BY-NC 4.0。

`numbers_long.csv` 是兩個模型（模型 A、模型 B）各自獨立萃取 5 篇中風上肢 RCT 的結果，整理成「一列一個數字」。為了不複製論文內容，**沒有原文引句**，只有「原文位置」（例如 Table 2）。

用 Excel 開啟即可（檔案含 BOM，繁中 Excel 不會亂碼）。共 220 列＝5 篇、每篇 2 組、每組 11 個欄位、2 個模型。

## 欄位說明

| 欄位 | 意思 |
|---|---|
| PMID | PubMed 論文編號 |
| 組序 | 該篇第幾組（兩個模型靠組序對齊，因為各自寫的組名可能不同） |
| 組別 | 模型寫下的組名（作者原文的組名） |
| 欄位 | `欄位名.子項`：`n_randomized.value`＝隨機分派人數；`n_analyzed.value`＝分析人數；`fma_ue_pre`／`post`／`change`＝前測／後測／變化量；子項 `mean`＝平均、`dispersion`＝離散（SD、SE 等的數值）、`dispersion_type`＝離散的種類 |
| 數值 | 照原文抄的值；原文沒報寫 `Unclear` |
| 單位 | 人數是「人」；FMA-UE 是「分」（量表 0–66 分）；離散類型是文字，單位空白 |
| 模型 | 模型A／模型B（兩個不同公司的 LLM；本資料不標哪個是哪個） |
| 是否Unclear | 數值是 Unclear（或空白）寫「是」 |
| 原文位置 | 模型回報的位置，例如 Table 2。這是模型寫的，可能有誤，核對時以原文為準 |

## 注意

- 這些是 LLM 的萃取結果，**沒有經過本文作者逐格核對原文**，不可直接當作論文的數據引用。
- 兩個模型都寫 Unclear，可能是論文真的沒報，也可能是兩邊都漏看，要抽查。
- 一致與否不代表正確：兩個模型也可能犯一樣的錯。
