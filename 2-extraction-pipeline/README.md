# 大量論文萃取：照正確方式做一次的迷你專案

> 授權：程式 MIT、文件 CC BY-NC 4.0。

## 這是什麼

這是一個「事後重做」的示範。原本的專案要從上千篇論文裡萃取方法層資訊；當時是邊做邊踩坑，**沒有每一步都照下面的順序做到**，很多規則是出了錯才補寫的。這裡把同一套做法，縮小成 5 篇中風上肢復健的隨機對照試驗（RCT），**從頭照六個階段做一遍**，每個階段都留下檔案，讓你照著做就能用在自己的題目。

誠實說明兩件事：

1. 這份 SOP 是「整理後應該怎麼做」，不是原專案當時的實際過程。原專案是邊做邊補，當時沒有每一步都做到；這裡不逐項列出。
2. 5 篇的萃取結果與比對只是示範流程，**不代表中風復健的任何臨床結論**，也不判定哪個模型比較準。

## 原專案當初為什麼這樣規劃

講者自述，三個決定各有理由：

| 決定 | 為什麼 |
|---|---|
| **檢索範圍**：不只收某訓練機構公布的論文，也擴大到這些作者後來的發表與合作 | 一是只看公布的論文，篇數太少；二是想看這套寫法是課程教出來的，還是這群作者本來就這樣寫 |
| **萃取流程**：兩條管線，問的是不同問題 | 第一條了解通用做法（大家做了哪些步驟），第二條分析細項做法（參數設多少、引用哪幾篇）。第二條原本不是為了驗證而做；兩條一比，才發現第一條算錯了 Stata 使用率。從此「重要的數字要有第二條路」變成規則 |
| **知識庫**：一開始就打算把結果做成知識卡 | 當作之後請 AI 協作時的參考知識庫，不只是存檔 |

這也是本資料夾 `01_plan/` 要你一開始就寫清楚的三件事：範圍、每一步要回答的問題、結果最後放哪裡。

## 你需要先準備什麼

- 一台 Windows 或 Mac 電腦，已安裝 Python 3.9 以上（只用標準庫，不需要另外裝套件）。
- 一個可以放檔案的資料夾（下載本 repo 後直接用）。
- 做自己的專案時：至少兩個不同來源的 LLM 帳號（例如兩家不同公司的模型），以及你有權使用的論文全文。
- 名詞：LLM＝大型語言模型（會讀文字、回文字的 AI）；API＝讓程式互相講話的窗口；DOI＝論文的永久編號；PMID＝PubMed 的論文編號；RCT＝隨機對照試驗。

## 照順序做

1. 打開 `01_plan/README.md`，用「專案說明書範本」寫你自己的說明書；先看「填好的 5 篇示範版」。
2. 若要請多個 AI 代理查資料，進 `02_research/`。
3. 取得全文進 `03_sources/`；先跑 `check_doi.py` 範例確認工具能用。
4. 設計萃取進 `04_extract/`。
5. 比對與查核進 `05_verify/`；實跑 `compare_extractions.py` 重現 110 格。
6. 做完（或出錯）回 `06_iterate/` 記錄、寫規則，再回到 01。

## 快速自我檢查（約 1 分鐘）

在本資料夾（`2-extraction-pipeline`）開終端機（Windows 用 PowerShell，Mac 用「終端機」），逐行貼上：

```
python 05_verify/compare_extractions.py --csv 04_extract/examples/numbers_long.csv --labels 模型A 模型B --out compare_report.md
```

為什麼要跑：確認你的 Python 能跑、並重現本專案的比對結果。預期看到：`比對 110 格：一致 82、不一致 8、都 Unclear 20；一致率 91%（分母 90）`，並產生 `compare_report.md`。沒看到：確認終端機目前位置是 `2-extraction-pipeline`，且指令是 `python`（Mac 可能要改 `python3`）。若中文顯示成亂碼，Windows 先執行 `chcp 65001`。

## 哪裡用 LLM、哪裡一定要人

- 用 LLM：草擬說明書、查資料、萃取數字、第二條管線、重算、整理失敗成規則草稿。
- 一定要人（★）：定題目與紅線、核准開工、決定採納哪些資料、看有疑問的檔案、不一致格子回原文裁決、核准規則。
- LLM 的輸出一律當「草稿」；沒有人看過原文的數字，不可進論文。

## 限制

- 5 篇只夠示範流程，不夠算統計；一致率 91% 不是模型準確率，只是兩個模型彼此相同的比例（兩個模型也可能犯同一個錯）。
- 本 repo 不含任何論文全文、PDF、原文引句；示範資料只有數字與「原文位置」（例如 Table 2）。
- Crossref 查不到撤稿紀錄，不等於論文沒被撤稿。
- 所有數字是「講者專案聚合統計」，是倖存者樣本（已發表成品），給預設值參考，不是「這樣做才對」的保證。
