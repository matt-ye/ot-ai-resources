# SOP 04：人抽查原文

> 授權：CC BY-NC 4.0。

## 為什麼

前三種方法都沒有真正回到原文。只有人（或另一份被獨立驗證過的資料）能確認「論文裡到底寫什麼」。

## 抽樣建議（示範設定，依你的題目與風險調整）

| 類別 | 抽多少 |
|---|---|
| 兩個模型「不一致」的格子 | **全部** |
| 「都 Unclear」的格子 | 至少抽 1 篇完整看；若這一類很多，抽更多 |
| 「一致」的格子 | 隨機抽一部分（例如 10%），確保不是兩邊犯同一個錯 |
| 離散類型（SD／SE） | 建議全看，因為標錯類型影響大 |

## 做法（人★）

1. 打開 `compare_report.md` 的「不一致清單」，每一列有 PMID、組序、欄位、兩邊的值、兩邊報的位置。
2. 打開該論文全文，到報的位置（例如 Table 2）找這個數字。若位置寫得不對，在全文裡自己找。
3. 在 `人工裁決紀錄_空白範本.csv` 新增一列：

| 欄 | 填什麼 |
|---|---|
| PMID／組序／欄位 | 抄報告 |
| 模型A值／模型B值 | 抄報告 |
| 原文實際寫的 | 你看到的值與位置（不要貼原文整段） |
| 裁決 | A 對／B 對／兩邊都錯／原文沒報／無法判定 |
| 備註 | 為什麼；例如「表格與內文不同」 |
| 裁決人與日期 | |

4. 發現原文本身前後矛盾（例如表格與內文數字不同）：裁決寫「無法判定」，備註兩處的位置，交給負責人決定採用哪一個。
5. 若發現同一種錯重複出現（例如某個模型一直把 SE 當 SD），回 `06_iterate/` 寫成規則。

## 重要

- 人的裁決也要留紀錄，包括「我也不確定」。
- 本專案公開的資料**不含**裁決結果；你自己的專案請把裁決紀錄放在說明書指定的位置。
