# SOP 03：沒參與的代理重算

> 授權：CC BY-NC 4.0。

## 為什麼

做事的人（或 AI）容易「自己驗自己」：用同一套想法算一次，當然得到同一個答案。請一個**沒看過你的程式與推理**的新代理，只憑原始檔與指標定義重算，兩邊的數字對不上，就是有 bug 或定義不清。

## 做法

1. **（人★）列出要重算的指標**，每個寫成一句定義。例如「一致率＝一致格數 ÷（一致格數＋不一致格數）」。
2. **（人★）準備原始檔**：只給 `numbers_long.csv` 之類的原始資料，**不給**你的比對程式、報告與你算出的數字。
3. **（LLM）開全新對話，貼下面的 prompt。**
4. **（程式＋人★）對帳。** 把你的數字與它的數字放一起；一致就過；不一致就逐項查是誰錯。

## Prompt（貼上，再附原始檔與指標定義）

```
你是獨立重算員，沒有參與前面的工作。
我給你原始資料檔與若干指標的定義。請你自己寫程式（Python 標準庫即可）或用最直接的方法重算每一個指標，並回報：
1. 每個指標的數值與分母。
2. 你用的程式或步驟（簡短）。
3. 定義裡有模糊的地方，你怎麼解讀。
規則：
- 你不會收到、也不要猜測別人算出的數字。
- 資料有缺漏或格式怪異時，寫出來，不要靜默略過。
- 禁止再派子代理。
```

## 實例（講者專案聚合統計）

原專案請沒參與的代理重算分層設計的 16 項指標：13 項與原來一致；其餘中抓到 1 個真正的程式錯誤（中文文字後面用英文的「詞界」符號判斷，在中文裡不成立，造成 178 筆誤判），其餘項目的原因本文未逐項確認。分母：16 項指標。

## 限制

- 重算員也是 LLM，可能和你犯同一種誤解；定義寫得越明確越好。
