# 4 所需資源清單

> 先看「必要」那一欄就好。沒有一項需要一開始就付錢。申請步驟、額度與資料政策寫在[資源手冊第 9 章](../handbook/README.md#免費-api-與金鑰保管)，查證日期 2026-10-19，使用前以官方頁為準。

## 一、依你要做的事

| 你想做 | 必要 | 選用 |
|---|---|---|
| 只追文獻、不寫程式 | My NCBI 帳號（PubMed Create alert） | — |
| 1 文獻雷達（自己電腦跑） | Python 3 | 一家免費 LLM 金鑰（讓 AI 幫你篩） |
| 1 文獻雷達（每月自動跑） | GitHub 帳號 | NVIDIA NIM、Groq、Cloudflare 金鑰，各一把，當備援 |
| 2 萃取管線 | Python 3、一個 LLM（聊天版也可以先試） | Claude Code 等能讀寫檔案的 agent；第二家模型，用來互相比對 |
| 3 知識庫 | Obsidian | Claude Code 等 agent；Python 3 或 PowerShell（格式自動檢查） |
| 敏感資料 | 本機模型（資料不離開電腦） | 見手冊第 5 章 |

## 二、工具

| 工具 | 一句話 | 官方網站 | 必要 |
|---|---|---|---|
| Obsidian | 用資料夾與純文字檔做筆記，檔案都在自己電腦 | https://obsidian.md | 做知識庫必要 |
| Claude Code | 能在資料夾裡讀檔、寫檔、跑程式的 AI 助手 | https://code.claude.com/docs | 選用 |
| GitHub | 放程式與文件、開工作單、排程自動執行 | https://github.com | 雷達自動跑必要 |
| Python 3 | 跑本 repo 的小程式，只用內建功能，不用另外安裝套件 | https://www.python.org/downloads | 1、2 必要 |
| Zotero | 管理書目與 PDF | https://www.zotero.org | 選用 |

## 三、查文獻與找全文

| 服務 | 用在哪 | 要金鑰嗎 | 備註 |
|---|---|---|---|
| Europe PMC | 雷達檢索 | 不用 | 生醫文獻 |
| PubMed E-utilities | 檢索、編號查詢 | 不用（有金鑰較快） | 每秒有上限 |
| Crossref | 用 DOI 查書目、比對 | 不用 | 建議附 email，速度較穩 |
| NCBI 編號轉換 | DOI 轉 PMCID | 不用 | 一次可查多筆 |
| PMC 開放資料 | 下載開放取用全文 | 不用 | 只能用 PMC 官方列明的程式化服務；授權要逐篇看 |
| Unpaywall | 用 DOI 找合法開放版本 | 不用，但要附 email | — |
| OpenAlex | 找論文與開放版本 | 基本查詢不用 | 搜尋有每日額度 |
| 出版社官方 API | 取得有訂閱的全文 | 要申請 | 條款各家不同，先看清楚 |

## 四、讓 AI 篩選或判斷（免費額度會變）

| 服務 | 用在哪 | 備註 |
|---|---|---|
| NVIDIA NIM、Groq、Cloudflare Workers AI | 雷達篩選，三家輪替 | 程式不寫死模型名稱，會先查當期清單 |
| 其他（OpenRouter、Mistral、Google AI Studio） | 自己試 | 見手冊第 9 章 |

免費層的資料政策差異很大，**只放公開資料**。

## 五、金鑰保管五原則

1. 不貼進程式碼、文件、聊天、截圖或公開分享的文件。
2. 存在密碼管理器或電腦的「環境變數」，不要存成桌面文字檔。
3. 不同用途各用一把，方便單獨撤銷。
4. 疑似外洩立刻到後台撤銷並重建。
5. 定期看用量，異常就換；能設到期日與最小權限就設。
